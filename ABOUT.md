# О проекте

Данный проект создан для демонстрации настройки командной работы с GitHub, использования Issues, Pull Requests и ветвления.

**Основные особенности:**
- Работаем через отдельные ветки для каждой задачи (Issue)
- Оформляем Pull Request с обязательным ревью для ветки develop
- Используем Wiki и документацию для структурирования информации
